# Portfólio — Gabriel Arte

Projeto desenvolvido para a atividade de **Design Profissional — GitHub Foundations**.

## Objetivo

Criar um pequeno portfólio web para apresentar meu perfil acadêmico,
habilidades e projetos pessoais, aplicando conceitos básicos de Git e GitHub.

## Tecnologias

- HTML5
- CSS3
- Git
- GitHub

## Estrutura

```text
portfolio-gabriel/
├── index.html
├── README.md
└── css/
    └── style.css
```

## Conceitos de Git/GitHub aplicados

Neste repositório serão demonstrados:

- criação de repositório;
- commits organizados;
- branch separada da branch principal;
- Pull Request;
- merge;
- documentação com README.md.

## Projeto

O site apresenta informações acadêmicas e profissionais de Gabriel Arte,
estudante de Engenharia de Software interessado em programação e
